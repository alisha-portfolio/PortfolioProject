Full-stack web app · CraftSolve Hackathon 2026

FindIt Campus: Lost & Found Platform

A lost-and-found platform for MUET, built for CraftSolve Hackathon 2026. Lost-item notices in group chats and on notice boards get buried quickly, so FindIt gives students one place to report lost or found items (name, category, colour, description, location, date, optional photo) and to search and filter reports.

  • Smart matching: ranks possible lost/found pairs with a score and a short explanation. It only suggests; it never approves claims or handovers.
  • Admin dashboard: manage reports, review claims, link matching reports and track returned items.
  • Privacy first: names, emails and phone numbers stay hidden from public reports and are visible only to the authenticated administrator.
  • Safe handover: claims include private ownership proof and a claim code to check status; the administrator verifies ownership before an item is returned.
  • React 19
  • Vite
  • React Router
  • Node.js
  • Express
  • SQLite
  • Responsive CSS

A student hackathon and learning project, not a validated production system. Planned hosting: Vercel (frontend) and Render (backend).
